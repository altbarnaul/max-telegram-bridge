# Как подключить MAX Bridge

Пошаговая инструкция по настройке пересылки сообщений из MAX в Telegram.

## Что вам понадобится

- Аккаунт в MAX и телефон с приложением MAX
- Аккаунт в Telegram

## Шаг 1. Войдите в MAX через бота

1. Откройте в Telegram своего бота (как его завести — в README) и напишите `/start`

2. Нажмите **«📱 Подключить MAX»** — бот пришлёт QR-код

3. Отсканируйте QR камерой телефона, на котором установлен MAX (или откройте ссылку из подписи на этом телефоне) и подтвердите вход в приложении MAX

4. Бот ответит **«✅ MAX подключён»**

> QR-код действует 2 минуты; если не успели, бот пришлёт новый. Мост входит в MAX как отдельное устройство — web.max.ru и приложение на телефоне продолжают работать как раньше.

## Шаг 2. Создайте группу в Telegram

1. В Telegram создайте **новую группу**:
   - Нажмите ☰ → «Создать группу»
   - Название: любое (например, «MAX Сообщения»)
   - Добавьте **бота** в участники группы

2. **Включите режим форума** (топики):
   - Откройте настройки группы (нажмите на название)
   - Найдите раздел **«Темы»** (Topics) — включите его

3. **Сделайте бота администратором**:
   - Настройки группы → Администраторы → Добавить администратора
   - Выберите **бота**
   - **Обязательно** включите право **«Управление темами»** (Manage Topics)
   - Сохраните

## Шаг 3. Запустите бота в группе

Напишите в группе команду:

```
/setup
```

Бот автоматически создаст **4 топика**:

| Топик | Что в нём |
|-------|-----------|
| **Личные** | Личные сообщения (DM) |
| **Группы** | Групповые чаты |
| **Каналы** | Посты из каналов |
| **Комментарии** | Зарезервирован под комментарии к постам (пока пустует) |

После этого бот напишет: **«✅ MAX Bridge настроен! Сообщения начнут поступать в топики.»**

## Готово!

Все новые сообщения из MAX будут автоматически появляться в соответствующих топиках группы.

### Как отвечать из Telegram в MAX

Чтобы ответить на сообщение из MAX:
1. Откройте нужный топик
2. **Ответьте** (Reply) на конкретное сообщение
3. Ваш ответ будет автоматически отправлен обратно в MAX

### Команды бота

| Команда | Где | Что делает |
|---------|-----|------------|
| `/start` | Личные сообщения | Начать подключение |
| `/login` | Личные сообщения | Заново войти в MAX по QR-коду |
| `/status` | Личные сообщения | Проверить статус подключения |
| `/stop` | Личные сообщения | Приостановить пересылку |
| `/setup` | В группе | Создать топики и запустить пересылку |
| `/support <текст>` | Личные сообщения | Написать в поддержку |
| `/help` | Личные сообщения | Справка |

## Решение проблем

**Бот не отвечает на /start**
→ Убедитесь, что пишете **боту** в личных сообщениях (не в группе)

**QR-код истёк или вход не подтверждён**
→ Напишите /login — бот пришлёт новый QR-код

**Бот написал «MAX отозвал вход моста»**
→ Напишите /login и отсканируйте QR-код — группа и топики останутся прежними

**Бот не создаёт топики по /setup**
→ Проверьте: (1) в группе включены Темы, (2) бот — администратор, (3) у бота включено право «Управление темами»

**Сообщения не приходят**
→ Напишите /status боту в личных сообщениях — проверьте статус подключения
